# Vehicle Data Chatbot

A lightweight local web app that downloads U.S. vehicle sales and official EPA fuel-economy data, then answers common numeric questions from the downloaded records.

## Run

Requires Python 3.10+ and uses only the Python standard library, so there is no package-install step.

On Windows, the easiest way to download the data and launch the app is to double-click `run_chatbot.bat` (see [One-click Windows setup](#one-click-windows-setup)).

To run it manually, download each data source first, then start the server:

```powershell
python download_data.py sales 2025
python download_data.py sales 2026
python download_data.py epa
python app.py
```

1. Download or clone this project on your computer.
2. Open PowerShell in the project folder.
3. Run the three `python download_data.py ...` commands above in order.
4. Run `python app.py`.
5. Open <http://127.0.0.1:8000> in your browser and ask questions such as:

- "How many Honda CR-Vs sold in 2025?"
- "Which model sold the most in 2025?"
- "Which car has the best mileage?"
- "Which electric car has the best mileage in 2026?"

If port 8000 is already in use, choose another port in PowerShell and open that address instead:

```powershell
$env:PORT = "8001"
python app.py
```

Then open <http://127.0.0.1:8001>.

## One-click Windows setup

On Windows, double-click `run_chatbot.bat` to download 2025 sales, 2026 sales, and EPA mileage in order, then start the chatbot and open it in your browser. Keep the chatbot server window open while using the site. Close that window to stop the server. If port 8001 is already in use, open PowerShell in this folder, run `$env:PORT = "8002"`, then run `.\run_chatbot.bat`; alternatively, use the manual steps above.

The same downloads can be run one at a time from PowerShell:

```powershell
python download_data.py sales 2025
python download_data.py sales 2026
python download_data.py epa
```

Data is saved locally in `data/sales.json` and `data/mileage.json`. These files are generated by the downloader commands and are not committed. The browser app is for chatting only; it has no download controls.

## How it works

- `downloaders/sales.py` downloads and parses the monthly sales tables.
- `downloaders/epa.py` downloads EPA's CSV and keeps the selected model years.
- `download_data.py` saves each downloaded dataset locally.
- `run_chatbot.bat` runs all three downloads in sequence and only launches the app if they succeed.
- `chatbot.py` totals and ranks the downloaded records; it does not call an AI service.
- `app.py` serves the website and connects its buttons and chat form to the Python code.
- `public/index.html` is the simple web page.

The chatbot compares EPA vehicles to sales nameplates using exact make/model matches plus a few explicit pickup-name aliases. It does not guess when a name cannot be matched. Questions about best mileage are answered from the matched models and show the best EPA vehicle configuration, not a model-wide or sales-weighted average. Ask separately for electric vehicles (MPGe) or hydrogen vehicles (miles per kilogram); those units are not mixed with MPG.

## Sources and interpretation

- Sales: GoodCarBadCar's [2025](https://www.goodcarbadcar.net/2025-u-s-auto-sales-figures-by-model-all-vehicle-ranked-2/) and [2026](https://www.goodcarbadcar.net/2026-us-auto-sales-figures-by-model-all-vehicle-ranked/) monthly tables. The importer keeps only published numeric month values; blank/unknown values are not treated as zero. A published zero remains zero. Source coverage can vary by nameplate, and the source does not specify estimate status per row; the app preserves the source link and states this caveat. 2026 totals cover only months available in the source.
- Mileage: the official [FuelEconomy.gov vehicle CSV](https://www.fueleconomy.gov/feg/epadata/vehicles.csv), filtered to EPA model years 2025 and 2026. EPA rows are distinct trims/configurations, not a single rating per sales nameplate. The chatbot reports the highest matching loaded configuration, not a sales-weighted model average. Electric vehicle ratings are labeled MPGe and ranked separately from non-electric MPG; hydrogen vehicle ratings use miles per kilogram.

The chatbot uses deterministic local queries rather than an external LLM, so numeric answers are derived from downloaded data and do not require API credentials. Model names are not automatically fuzzy-matched across EPA and sales datasets.
